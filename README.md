# FloodGuard – Smart Flood Monitoring System

## Project Overview
FloodGuard V4 is a flood monitoring and early-warning prototype developed using **BBC Micro:bit V2** and **Microsoft MakeCode Blocks**. It simulates water-level changes and provides visual and sound alerts.

## Features
- Four risk categories: SAFE, RISING, WARNING and DANGER
- Risk category names and LED water-level display
- Manual water-level control using Buttons A and B
- Automatic rainfall simulation using A+B
- Touch logo to reset
- Water-level trend analysis and early-warning prediction

## How to Run
1. Download the `.hex` file from this GitHub repository.
2. Open [Microsoft MakeCode](https://makecode.microbit.org/).
3. Click **Import → Import File** and select the downloaded `.hex` file.
4. Open the project and run it in the Micro:bit simulator.

## Requirements
- Web browser
- Microsoft MakeCode
- BBC Micro:bit V2 simulator or physical device

## Limitations
The project uses simulated water-level data, not real sensors. It is intended for educational purposes only.
